### Links and privacy — release gate

- Crawl generated internal links and `#fragment` destinations; preserve existing routes. Validate browser/HTTP resolution from both `/projects/` and `/projects.html`.
- Enforce the private repository restriction with an explicit **nonzero exit code on failure**, rather than an unchecked `grep | head` pipeline. Inspect the actual `content/data.json` schema to obtain the private repository URL; do not copy that URL into `AGENTS.md`. Scan **all generated public text assets**, not only HTML (at minimum `.html`, `.js`, `.json`, `.xml`, `.css`, and `.txt`, including sitemap/feed files).
- A reusable example follows; verify it against the actual data schema before treating it as a release gate:

```bash
python3 - <<'PY'
import json
from pathlib import Path

data = json.loads(Path('content/data.json').read_text(encoding='utf-8'))

def objects(value):
    if isinstance(value, dict):
        yield value
        for child in value.values():
            yield from objects(child)
    elif isinstance(value, list):
        for child in value:
            yield from objects(child)

def strings(value):
    if isinstance(value, str):
        yield value
    elif isinstance(value, dict):
        for child in value.values():
            yield from strings(child)
    elif isinstance(value, list):
        for child in value:
            yield from strings(child)

private_entries = [obj for obj in objects(data) if obj.get('repository_public') is False]
if not private_entries:
    raise SystemExit('Privacy check inconclusive: no private repository entry found')

private_paths = set()
for entry in private_entries:
    for value in strings(entry):
        if 'github.com/' in value.lower():
            private_paths.add(value.lower().split('github.com/', 1)[1].split('?', 1)[0].rstrip('/'))
if not private_paths:
    raise SystemExit('Privacy check inconclusive: no private repository URL found in structured data')

public_ext = {'.html', '.js', '.json', '.xml', '.css', '.txt'}
files = [p for p in Path('dist').rglob('*') if p.is_file() and p.suffix.lower() in public_ext]
if not files:
    raise SystemExit('Privacy check inconclusive: no generated public text files found')

leaks = []
for path in files:
    text = path.read_text(encoding='utf-8', errors='replace').lower()
    if any(('github.com/' + repo_path) in text for repo_path in private_paths):
        leaks.append(str(path))
if leaks:
    raise SystemExit('Private repository URL exposed in: ' + ', '.join(leaks))
print(f'Privacy check passed across {len(files)} generated public text files')
PY
```

**Note:** This scan catches literal repository URLs. If the site begins constructing links dynamically or URL-encoding paths, extend the check to cover those representations and inspect rendered browser output.
